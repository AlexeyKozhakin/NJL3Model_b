# njl3.fast — быстрый алгоритм для фазовой диаграммы по (M, b)

Начато 2026-10-22. Цель — карта глобального минимума Ω(M, b) на R²×S¹ за секунды, в том числе в браузере
(отдельное приложение `web/fast/`), и аналитика каналов для статьи 2. Эталон — пакет `njl3.inh`
(медленный надёжный поиск) и его карты `web/lab/data/inh/maps_phi*_g*_*.json`.

## Решения (2026-10-22)

- План и методы — здесь (публично); выкладки для статьи — локально в `publication/paper2-full/fast/`.
- φ ∈ {0, 0.1, …, 0.5} (таблицы s_φ); произвольное φ — позже.
- T — свободный параметр (ползунок в приложении).
- Начинаем с аналитики (M2, M3): она же даёт ускорение.
- Новые эталонные карты пока не считаем; для сверки — готовые карты и отдельные точки.

## Структура задачи

Три области на плоскости (μ, L):
1. M велико, b = 0 — однородное решение (`njl3.hom`, точное и гарантированное).
2. M мало, но щель переживает T, b ≈ S_n — фазы B_n у порогов S_n = sqrt(μ² − k_n²).
3. M = 0 (b не определено).

Дорого только (2): численный поиск в каналах со щелью M ≳ 10⁻² (сетка 40×37 + Нелдер–Мид, ~1500 Ω на канал).

## Методы

| № | Метод | Суть | Статус |
|---|---|---|---|
| M1 | Однородный слой | `njl3.hom`: области 1, 3 и кандидат b = 0 | ✅ |
| M2 | A_n аналитически | Ω(M, S_n) = M²[A_n − c_n ln(1/M)] + …; A_n — сумма одномерных интегралов вместо разности Ω при M = 10⁻⁴ | ⬜ |
| M3 | Старшие порядки асимптотики | члены M⁴, M⁴ ln M и сдвиг b* − S_n; формула вместо поиска до M ~ 0.1–0.3 | ⬜ |
| M4 | Ньютон по уравнениям щели | ∂Ω/∂M = ∂Ω/∂b = 0 с аналитическими производными, 4–6 шагов | ⬜ |
| M5 | Продолжение по сетке | старт от решения соседней точки; полный поиск только при смене фазы | ⬜ |
| M6 | Слежение за границами | B_n↔T: T_c,n(μ, L) = T; B_n↔V/I и B_n↔B_m: равенство Ω | ⬜ |
| M7 | Интерполяция внутри фаз | M*, b* гладкие внутри фазы | ⬜ |
| M8 | Оценки глубины канала | строгий отсев каналов; шаг к гарантии в области 2 | ⬜ |

## Этапы

1. Каталог, план, профилирование тяжёлой карты (φ = 0.1, пики).
2. Аналитика M2 → M3 (проверка по численному Ω в каналах).
3. Эталон на Python: M4 + M5 (+ M3); сверка с картами `njl3.inh`.
4. JS-порт и `web/fast/`: карта в браузере с прогрессом, φ, g, T (ползунок), область.
5. M6 + M7: карта за секунды.
6. (Позже) произвольное φ.

## Критерии приёмки (против эталона)

- Фаза совпадает во всех клетках, кроме соседних с границей фаз.
- |Δ ln M*| < 10⁻³, |Δ b*| < 10⁻³.
- Карта 237×237 в браузере — не дольше ~10 с.
