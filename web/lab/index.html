Глобальный минимум однородного потенциала Ω(M) при b = 0 по массе M для химического потенциала μ и размера L. Граничное условие по окружности: ψ(x₂ + L) = e2πiφψ(x₂), моды kn = 2π(n + φ)/L (φ = 0 — периодическое, φ = ½ — антипериодическое). Карта считается в браузере с гарантированным поиском всех корней уравнения щели. Кликните по карте — справа Ω(M) и G(M), ниже срезы.

Формулы

  • G(M) = 1/g + M/π + (1/(πL))·ln[(1 − e−LM)² + 4e−LMsin²πφ] + (2/(πL))·Σn∈ℤ, mn<μ arccosh(μ/mn), dΩ/dM = M·G(M); mn = √(M² + kn²).
  • ΩL = (2/(πL³))·Re[LM·Li₂(z) + Li₃(z)], z = e−LM+2πiφ; при φ = 0 — формулы статьи 1.
  • Гарантия полноты: G = 1/g + A(M) + B(M), A = M/π + ln D/(πL) возрастает (A′ = (1 − e−2LM)/(πD) > 0), B = (2/(πL))Σ arccosh(μ/mn) убывает — метод ветвей и границ находит все корни.
  • φ и 1 − φ эквивалентны; при μ = 0 и малых L симметрия восстанавливается (M* = 0), если 4 sin²πφ > 1, т. е. φ > 1/6.

Глобальный минимум Ω(M, b) по массе M и параметру киральной спирали b. Фазы с b = 0 (V, Ij) — точное однородное решение; фазы Bj — минимум у порога уровня |kj|: b ≈ Sj = √(μ² − kj²), kn = 2π(n + φ)/L. У каждого порога логарифмическая неустойчивость, щель экспоненциально мала; физический порог — температура: щель канала исчезает при T > Tc = (eγ/π)(Sj/μ)M*j (серое — M = 0). Карты посчитаны заранее при T = 10⁻³ для φ = 0, 0.1, …, 0.5 и g = ±1; клик по карте — расчёт точки в браузере (порог T можно поменять).
