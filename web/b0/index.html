NJL₃ на ℝ²×S¹ при b = 0: фазовая диаграмма

Глобальный минимум потенциала Ω(M) по массе M при химическом потенциале μ и размере компактификации L (φ = 0, g = −1). Карта M* считается в браузере по замкнутым формулам с гарантированным поиском всех корней уравнения щели; линии переходов — точные решения уравнений (точность ~10⁻¹²). Кликните по диаграмме, чтобы увидеть Ω(M) и G(M) в точке.

Точка

Ω(M) − Ω(0)

G(M) = Ω′(M)/M

Модель и метод: замкнутые формулы при b = 0, уравнение щели dΩ/dM = M·G(M), монотонное разложение G = 1/g + A(M) + B(M) (A возрастает, B убывает) — гарантия, что найдены все минимумы. Версия 0.1.0.
