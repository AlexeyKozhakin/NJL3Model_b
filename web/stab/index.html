Модель ГН на ℝ²×S¹: устойчивость однородного решения

Однородное решение M*(μ, L) (при выбранных φ и g, включая симметричную фазу M* = 0) проверяется на устойчивость к неоднородной флуктуации δσ ∝ eiq₁x₁·ei2πkx₂/L. Вторая вариация действия Φ(k, q₁) < 0 означает, что однородная фаза неустойчива. Карта: минимум Φ по q₁ ∈ (0, 10] (и по k). Кликните по карте — справа появятся кривые Φ(q₁) в этой точке, они считаются прямо в браузере.

φ

синее — Φ > 0 при всех q₁, k: однородная фаза устойчива красное — есть q₁ с Φ < 0: неустойчива фаза T (M* = 0) — по формуле Φ = ½G(0⁺) + петля при M → 0; серое — ещё не посчитано

Точка

Φ(k, q₁)

Сплошные — T = 0, пунктир — T = 10⁻³. Вертикальные точки — особенности q₁ = Pn + Pn+k (при k = 0: q₁ = 2kF,n), где при T = 0 Φ → −∞ (логарифм); ось обрезана снизу.

Что здесь посчитано

  • Φ(k, q₁) = ∫dp₁/(2πL) Σn [2M² + q²/2] · (θ(En−μ)/En − θ(Enk−μ)/Enk)/(Enk² − En²), q² = q₁² + (2πk/L)², En = √(M² + p₁² + (2πn/L)²), Enk = √(M² + (p₁+q₁)² + (2π(n+k)/L)²) — формула Р. Н. Жохова после интегрирования по p₀ и подстановки уравнения щели (числитель симметризован, Φ(−k) = Φ(k)).
  • q₁ — импульс флуктуации вдоль бесконечного направления (непрерывный); k — число волн вдоль окружности длины L (целое): k = 0 — модуляция только вдоль x₁.
  • Знак: в вакууме Φ > 0; Φ < 0 — однородная фаза неустойчива к такой флуктуации.
  • Фаза V (M* ≥ μ): ферми-моря нет, Φ = Φvac > 0 — всегда устойчива. Фазы Ij (0 < M* < μ): у заполненного канала n логарифмическая особенность при q₁ = 2kF,n, при T = 0 Φ → −∞; при T > 0 (θ(E−μ) → 1 − nF(E−μ) − nF(E+μ)) она обрезается ~ln(1/T). Фаза T (M* = 0): уравнения щели нет, поэтому Φ = ½G(0⁺; μ, L, g, φ) + [Φvac + Φmat](M → 0), где G(0⁺) — функция щели однородной задачи в нуле; петля считается при малой массе M = 10⁻⁴ (зависимость от неё ~10⁻⁸). При q₁ → 0, k = 0 получается ровно ½G(0⁺). Это формула Р. Н. Жохова для M = 0, в которой у вклада ферми-моря множитель 1/L (а не 2/L): только так выполняется предел q₁ → 0.
