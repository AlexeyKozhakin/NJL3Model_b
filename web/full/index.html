NJL₃ на ℝ²×S¹: фазовая диаграмма по (M, b)

Глобальный минимум Ω(M, b) при φ = 0, g = −1. Фазы с b = 0 (V, Ij) — точное решение из случая b = 0; фазы Bn — минимум у порога моды b ≈ Sn = √(μ² − (2πn/L)²). У каждого порога логарифмическая неустойчивость: Ω ≈ M²[An − cnln(1/M)], поэтому щель M* не обращается в ноль, а бывает экспоненциально малой (карта M* — в логарифмической шкале). Карты посчитаны заранее; клик по точке — расчёт в браузере.

V — вакуумная (b = 0, M* = Mvac) Ij — промежуточная (b = 0, заполнены моды 0…j) Bn — канал у порога n (b* ≈ Sn) «асимпт.» — щель из формулы M* = exp(−An/cn − ½)

Каналы у порогов

Жирным — канал глобального минимума. ln M*: при асимптотике M* = exp(ln M*).

Ω(M, b) − Ω(0, 0) около точки

Синее — Ω < 0, красное — Ω > 0; пунктир — пороги b = Sn; звезда — глобальный минимум.

[Ω(M, Sn) − Ω(0)]/M² у порога

Асимптотика An − cnln(1/M) — прямая; где она ниже нуля, M = 0 неустойчив. Минимум Ω — при ln(1/M*) = An/cn + ½.
