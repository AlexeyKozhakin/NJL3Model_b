NJL₃ на ℝ²×S¹: фазовая диаграмма по (M, b)

Глобальный минимум Ω(M, b) при φ = 0, g = −1. Фазы с b = 0 (V, Ij) — точное решение из случая b = 0; фазы Bn — минимум у порога моды b ≈ Sn = √(μ² − (2πn/L)²). У каждого порога логарифмическая неустойчивость: Ω ≈ M²[An − cnln(1/M)], поэтому при T = 0 щель M* не обращается в ноль, а бывает экспоненциально малой. Физический порог даёт температура: щель канала n исчезает при T > Tc,n = (eγ/π)(Sn/μ)M*n ≈ 0.57·(Sn/μ)M*n. Карты посчитаны для порога T = 10⁻³: щели, которые его не переживают, считаются нулевыми (серое — M = 0). Карты посчитаны заранее; клик по точке — расчёт в браузере с тем же порогом.

Точка

Каналы у порогов

Жирным — порог, у которого лежит глобальный минимум. «< порога» — щель канала не переживает T, канал отброшен. Поиск в соседнем канале может найти ту же яму (одинаковые строки). * — щель из асимптотики.

Ω(M, b) − Ω(0, 0) около точки

Синее — Ω < 0, красное — Ω > 0; пунктир — пороги b = Sn; звезда — глобальный минимум.

[Ω(M, Sn) − Ω(0)]/M² у порога

Асимптотика An − cnln(1/M) — прямая; где она ниже нуля, M = 0 неустойчив. Минимум Ω — при ln(1/M*) = An/cn + ½. Численная кривая — от M = 10⁻⁶ (ниже — шум округления). Серая полоса — щели меньше Mmin = T/(0.57·Sn/μ), не переживающие T.

Срезы через минимум

Ω(M*, b) − Ω(0, 0)

Ω(M, b*) − Ω(0, 0)

Два среза двумерной карты Ω(M, b) через глобальный минимум (звезда): слева M = M* фиксировано, меняется b; справа b = b* фиксировано, меняется M. «У минимума» — b* ± 8M* и M ∈ [0, 3M*] (у порога яма по b шириной ~M*); «широко» — b ∈ [0, μ + 1], M ∈ [0, max(2, 1.5M*)]. Пунктир — пороги b = Sn; серая полоса — щели меньше Mmin(T).

Случай b = 0: фазовая диаграмма при b = 0. Версия 0.1.0.
