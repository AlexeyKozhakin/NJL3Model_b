# NJL3Model_b

Фазовая структура модели Намбу–Йона-Лазинио в 2+1 измерениях на $\mathbb{R}^2\times S^1$
при химическом потенциале $\mu$ и размере компактификации $L$.

Пакет **`njl3.b0`** решает случай $b=0$ ($\varphi=0$, $g<0$):

- замкнутые формулы для перенормированного потенциала $\Omega(M)$ и уравнения щели $G(M)$;
- **гарантированный** поиск глобального минимума по $M$: доказано, что находятся все корни
  уравнения щели;
- линии фазовых переходов (1-го и 2-го рода) как решения уравнений с точностью $\sim10^{-12}$;
- особые точки: пики (явная формула), критические концевые точки.

Общий случай $(M,b)$ — численный код в `functions/` и `gpu/` (в разработке).

## Установка

## Быстрый старт: командная строка

```bash
njl3-b0 point --mu 3.15 --L 3.5          # одна точка
njl3-b0 peaks --L-max 10                 # пики mu_n = 2πn/L_n по явной формуле
njl3-b0 diagram --mu 2.5 4 --L 0.1 10 --n 300 300 --out map.npz --plot map.png --vmax 4
njl3-b0 lines --mu 0.05 7 --L 0.1 10 --nL 400 --out lines.json --plot lines.png
```

Тот же интерфейс: `python -m njl3.b0 ...`. По умолчанию $g=-1$ (ключ `--g`).

## Python API

```python
from njl3.b0 import analyze_point, find_minimum, trace_L, peak, mu_stability

r = analyze_point(mu=3.15, L=3.5, g=-1.0)
r.phase, r.M_star, r.roots          # 'I1', 0.8935..., [(M, 'min'|'max'|'touch'), ...]

M_star, dOmega, minima = find_minimum(3.15, 3.5, -1.0)
trace_L(3.5, -1.0)                  # переходы по mu при L = 3.5: V→I0, I0→I1, I1→T (2-й род)
peak(2, -1.0)                       # (L_2, mu_2) = (3.7293741534, 3.3695655350)
mu_stability(1.0, -1.0)             # граница устойчивости M = 0: 2.4052386905
```

## Фазы

| Метка | Условие | Смысл |
|---|---|---|
| `V` | $M^*=M_{\rm vac}(L)\ge\mu$ | вакуумная, ферми-шар пуст; от $\mu$ не зависит |
| `I<j>` | $0<M^*<\mu$ | промежуточная; заполнены KK-моды $n=0,\dots,j$ |
| `T` | $M^*=0$ | тривиальная |

## Форматы данных

**`diagram`** (`.npz`, `.json` или `.csv`). Массивы формы `(N_L, N_mu)`:

| Поле | Содержание |
|---|---|
| `mu`, `L` | сетки |
| `M_star` | глобальный минимум $M^*$ |
| `omega_star` | $\Omega(M^*)-\Omega(0)$ |
| `phase` | метка фазы |
| `n_minima` | число локальных минимумов $M>0$ |

В CSV — по строке на точку: `L, mu, M_star, omega_star, phase, n_minima`.

**`lines`** (`.json`):

```json
{
  "g": -1.0, "mu_range": [0.05, 7.0], "L_range": [0.1, 10.0],
  "lines": {
    "V-T":   [{"L": ..., "mu": ..., "order": 1, "M_left": ..., "M_right": ...}, ...],
    "I1-T":  [...], "I0-I1": [...], ...
  },
  "special": [
    {"kind": "peak", "n": 1, "L": 1.6113000800, "mu": 3.8994507512},
    {"kind": "critical_end", "L": 1.2226473, "mu": 2.7909025},
    {"kind": "tricritical", "L": ..., "mu": ..., "on_phase_boundary": false}
  ]
}
```

`order`: 1 — переход 1-го рода (скачок $M^*$), 2 — 2-го рода.

## Метод (кратко)

1. При $b=0$ все вклады в $\Omega$ берутся в элементарных функциях и полилогарифмах.
   $d\Omega/dM=M\,G(M)$, логарифмические особенности у $M=0$ сокращаются.
2. На $[0,\mu]$ $G=1/g+A(M)+B(M)$, где $A$ возрастает, а $B$ убывает. Отсюда вилка
   $1/g+A(p)+B(q)\le G\le 1/g+A(q)+B(p)$ на $[p,q]$ и деление пополам с отсечением, которое
   находит **все** корни. На $[\mu,\infty)$ $G$ монотонна: не больше одного корня.
3. Около $M=0$ используются устойчивые формы $G$, $G'$ и $\Omega(M)-\Omega(0)=\int_0^M m\,G\,dm$.

Точность против mpmath (50 цифр): $G$ — $10^{-14}$, корни — $7\cdot10^{-15}$,
линии — $\le3\cdot10^{-13}$. Подробности:
[publication/notes/](publication/notes/), черновик статьи:
[publication/paper1-b0/draft/](publication/paper1-b0/draft/).

## Веб-приложение

`web/b0/` — интерактивная фазовая диаграмма в браузере (без сборки и без сервера вычислений):
карта $M^*(L,\mu)$ считается в фоновых потоках по тем же формулам (JS-порт
`web/b0/js/njl3b0.js`, совпадает с Python до $\sim10^{-13}$), поверх — точные линии переходов
из `web/b0/data/phase_lines.json`; клик по точке показывает $\Omega(M)$, $G(M)$, корни и минимумы.
Параметры вида сохраняются в ссылке; экспорт карты (CSV), линий и точки (JSON).

Локально (нужен любой HTTP-сервер — фоновые потоки не работают с `file://`):

```bash
python -m http.server 8000      # затем открыть http://localhost:8000/web/b0/
python web/b0/build_data.py     # пересчитать линии переходов (несколько минут)
```
