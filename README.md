# NJL3Model_b

## Описание

Этот проект предназначен для численного моделирования термодинамических свойств 3-мерной модели Намбю — Жона-Лазинио (NJL).

## Вычисляемые интегралы

В коде реализовано численное вычисление термодинамического потенциала и связанных с ним физических величин. Основные интегралы имеют вид:

### Термодинамический потенциал (пример)

$$
\Omega(L, b, M) = \int_0^1 du_1 \int_0^1 du_3 \, f(u_1, u_3, L, b, M, \varphi)
$$

где $f(u_1, u_3, L, b, M, \varphi)$ — выражение, содержащее логарифмы и экспоненты, зависящие от параметров модели.

### Интеграл для dU

$$
U(b, M) = \int_0^1 du \int_0^{\pi/2} d\varphi \, g(u, \varphi, b, M)
$$

где $g(u, \varphi, b, M)$ — выражение, содержащее корни и квадраты параметров.

### Интеграл по дискретным квантовым числам

$$
\Omega_{\mu, L}(\mu, L, b, M) = \sum_n \int_{p_{\text{left}}}^{p_{\text{right}}} dp_1 \, h(p_1, n, M, b, L, \varphi, \mu)
$$

где пределы интегрирования $p_{\text{left}}, p_{\text{right}}$ зависят от параметров, а $h$ — выражение для вклада соответствующего состояния.

## Использование

Запуск основного расчёта:

```bash
python main.py
```

Результаты сохраняются в файл `Omega_ren_phys.npy`.
