# Автоматические тесты

Директория для `pytest`-совместимых тестов. Запуск:

```bash
pytest tests/
```

Или отдельный файл:

```bash
pytest tests/test_b_symmetry.py -v
```

## Пакет njl3.b0 (случай b = 0)

```bash
pytest tests/b0 -m "not slow"   # быстрые, ~1 с
pytest tests/b0                 # все, включая сверку с численными интеграторами
```

- `b0/test_formulas.py` — формулы против mpmath, сокращение логарифмов, G′, G₂, монотонное разложение, устойчивая Ω.
- `b0/test_minimize.py` — корни против mpmath, полнота поиска против плотного скана, известные значения, фазы.
- `b0/test_lines.py` — линии μ_s, μ_VT, пики и их асимптотика, трассировка, критическая концевая точка, сверка с интеграторами.

## Структура

- `test_b_symmetry.py` — регрессионная проверка симметрии потенциала относительно $b \to -b$.
