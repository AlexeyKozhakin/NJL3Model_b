Алгоритмы, интегралы и структура кода

1. Общая структура потенциала

Перенормированный потенциал записывается как сумма четырёх вкладов:

$$ \Omega_{\text{ren}}(M, b; \mu, L, g) = \underbrace{\frac{M^2}{2g}}_{\text{вакуум}} + \underbrace{\Delta U_{\text{phys}}}_{\text{контрчлен}} + \underbrace{\Omega_{L,\text{phys}}}_{\text{размерные моды}} + \underbrace{\Omega_{\mu L,\text{phys}}}_{\text{плотность/μ-член}} $$

Каждый физический (перенормированный) член строится по схеме вычитания:

$$ X_{\text{phys}}(M, b) = X(M, b) - X(0, b) + X(0, 0) $$

Это гарантирует, что $\Omega_{\text{ren}}(0, 0) = 0$ и при $M = 0$ все $b$-зависимости взаимно сокращаются.

Важно: при $M = 0$ потенциал математически не зависит от $b$. Поэтому в численном алгоритме введена канонизация: если найденный минимум имеет $M < 0.05$, принудительно ставим $M = 0, b = 0$.

2. Вакуумный член

$$ \Omega_{\text{vac}} = \frac{M^2}{2g} $$

При $g = -1$ (отталкивающее взаимодействие) этот член отрицателен и стимулирует ненулевую массу $M > 0$.

3. Контрчлен ΔU (functions/dU.py)

3.1. Что вычисляет

$\Delta U$ — это ультрафиолетовый контрчлен, компенсирующий расходимости. В модели он имеет вид:

$$ \Delta U(M, b) = -\frac{N_c}{\pi} \int_0^{\Lambda} dp \, p \left[ E_p(M, b) - E_p(0, b) \right] $$

где $N_c = 2$ (число цветов), $\Lambda$ — ультрафиолетовый отрезок, а энергия:

$$ E_p(M, b) = \sqrt{(\sqrt{M^2 + p^2} + b)^2} = |\sqrt{M^2 + p^2} + b| $$

3.2. Алгоритм

В коде functions/dU.py:

  • Интеграл берётся методом средних точек (midpoint rule) с $N_h$ шагами
  • Пределы: $p \in [0, \Lambda_{\max}]$
  • Результат кэшируется через lru_cache
def fun_dU_phys(b_vals, M_vals, N_h_p, N_h_phi):
    # Интегрирование по p методом средних точек
    for i in range(N_h):
        p = p_left + (i + 0.5) * dp
        E = sqrt((sqrt(M^2 + p^2) + b)^2)
        total += E * p * dp
    return -Nc/pi * total

Сложность: $O(N_h)$ на вызов. После JIT-компиляции Numba — ~0.01 мс.

4. Размерные моды Ω_L (functions/Omega_L.py)

4.1. Физический смысл

$\Omega_L$ описывает вклад компактифицированного измерения $L$ (размер системы в направлении $y$). При $L \to \infty$ этот член исчезает; при $L \to 0$ доминирует.

$$ \Omega_L(L, M, b) = \frac{1}{L} \sum_{n=-\infty}^{\infty} \int_0^{\infty} dp \, p \ln\left[ 1 + \exp\left(-L \cdot E_{p,n}\right) \right] $$

где $E_{p,n} = \sqrt{(\sqrt{M^2 + p^2} + b)^2 + \left(\frac{2\pi n}{L}\right)^2}$.

4.2. Алгоритм

В коде functions/Omega_L.py:

  • Сумма по модам $n$ обрывается при $n_{\max} \sim L \cdot \Lambda / (2\pi)$
  • Каждая мода: интеграл по $p$ методом средних точек
  • Симметрия: моды $+n$ и $-n$ дают одинаковый вклад (кроме $n=0$)
def fun_Omega_L(L, b, M, phi=0, N_h_p1=200, N_h_p2=200):
    Nmax = floor(L * Lambda / (2*pi))
    total = 0.0
    for n in range(-Nmax, Nmax+1):
        E_n = sqrt((sqrt(M^2+p^2)+b)^2 + (2*pi*n/L)^2)
        integrand = p * ln(1 + exp(-L * E_n))
        total += integral(integrand, p)
    return total / L

Сложность: $O(N_{\max} \cdot N_h)$. После JIT — ~0.05 мс.

5. μL-член — самая сложная часть (functions/Omega_mu_L.py)

5.1. Физический смысл

$\Omega_{\mu L}$ описывает вклад химического потенциала $\mu$ при $T = 0$. Это аналог энергии заполнения Ферми:

$$ \Omega_{\mu L}(\mu, L, M, b) = -\frac{2}{L} \sum_{s=\pm} \sum_{n=0}^{n_{\max}^{(s)}} w_n \int_{\mathcal{D}_n^{(s)}} \frac{dp}{2\pi} \left[ \mu - E_{p,n}^{(s)} \right]_{+} $$

где $[x]_{+} = \max(x, 0)$, $w_0 = 1$ и $w_{n>0} = 2$ (учёт $+n$ и $-n$), а энергия дисперсии:

$$ E_{p,n}^{(\pm)} = \sqrt{(\sqrt{M^2 + p^2} \pm b)^2 + \left(\frac{2\pi n}{L}\right)^2} $$

5.2. Подынтегральная функция

$$ F_{\pm}(p, n) = \frac{1}{2\pi} \left[ \mu - E_{p,n}^{(\pm)} \right]_{+} $$

5.3. Ключевой вопрос: пределы интегрирования

Интеграл берётся не от 0 до $\infty$, а только там, где $F > 0$, то есть $E_{p,n} < \mu$.

Случай «один корень» (обычный)

Уравнение $E_{p,n} = \mu$ даёт один корень по $p$:

$$ p_{\max} = \sqrt{\left( \sqrt{\mu^2 - \left(\frac{2\pi n}{L}\right)^2} \mp b \right)^2 - M^2} $$

Интеграл: $\int_0^{p_{\max}} F(p, n)\, dp$.

Случай «два корня» (особый, $|b| > M$ и $b < 0$)

При определённых условиях ($|b| > M$, $b < 0$, $F(0) < 0$) функция $F(p, n)$ может быть положительна на двух несвязных интервалах по $p$:

$$ F > 0 \quad \text{на} \quad [p_{\text{left}}, p_{\text{right}}] $$

где:

$$ p_{\text{left}} = \sqrt{(|b| - S_n)^2 - M^2}, \qquad p_{\text{right}} = \sqrt{(|b| + S_n)^2 - M^2} $$

и $S_n = \sqrt{\mu^2 - (2\pi n/L)^2}$.

Критический баг, который мы исправили: в оригинальном коде случай «два корня» обрабатывался неверно — интеграл брался от 0 до $p_{\text{right}}$, пропуская область $[0, p_{\text{left}}]$, где $F < 0$ (функция не определена). Это давало нефизичные результаты. Сейчас корректно интегрируется только на $[p_{\text{left}}, p_{\text{right}}]$.

5.4. Алгоритм в коде

@jit(nopython=True)
def _compute_Unp(M, b, L, mu, phi, N_h):
    Nmax = n_max_plus(M, b, L, mu, phi)
    if Nmax < 0: return 0.0
    
    total = 0.0
    for n in range(Nmax + 1):
        Sn = sqrt(mu^2 - (2*pi*n/L)^2)
        F0 = Fpn_plus(0.0, n, M, b, L, phi, mu)
        
        # Проверка: два корня?
        two_roots = False
        if abs(b) > M and b < 0 and F0 < 0.0:
            val_left = (abs(b) - Sn)^2 - M^2
            val_right = (abs(b) + Sn)^2 - M^2
            if val_left >= 0 and val_right >= 0:
                two_roots = True
                p_left = sqrt(val_left)
                p_right = sqrt(val_right)
        
        if not two_roots:
            # Один корень: от 0 до p_right
            pr_sq = (Sn - b)^2 - M^2   # если b >= 0
            p_left = 0.0
            p_right = sqrt(pr_sq)
        
        # Интегрирование методом средних точек
        integral = _integrate_mode_scalar(0, n, M, b, L, phi, mu, N_h, p_left, p_right)
        total += (integral if n == 0 else 2.0 * integral)
    
    return total

5.5. Определение n_max

Максимальное число мод определяется из условия $S_n^2 > 0$:

$$ n_{\max}^{(+)} = \left\lfloor \frac{L}{2\pi} \sqrt{\mu^2 - (M + b)^2} \right\rfloor $$

(для «+» ветви; для «−» аналогично с $M - b$).

6. Поиск минимума: differential evolution

6.1. Постановка

Для фиксированных $(\mu, L)$ ищем:

$$ (M_{\min}, b_{\min}) = \arg\min_{M \in [0, M_{\max}],\; b \in [0, b_{\max}]} \Omega_{\text{ren}}(M, b) $$

6.2. Почему DE, а не Nelder-Mead

МетодПлюсыМинусы
Nelder-Mead Быстрый, локальный Пропускает узкие минимумы шириной ~0.2–0.4
DE (differential evolution) Глобальный, находит узкие ямы Много вызовов функции (~75)
Ключевое открытие: при $g = -1$ минимум по $b$ имеет ширину ~0.2–0.4 и глубину $\Delta\Omega \sim 10^{-3}$. Nelder-Mead с начальной симплекс-точкой $b = 0$ никогда не находит этот минимум. DE с popsize=5 и maxiter=15 находит корректно.

6.3. Параметры DE

  • bounds: $M \in [0, 10]$, $b \in [0, 10]$
  • maxiter: 15 (итераций)
  • popsize: 5 (размер популяции = 5 × dim = 25 точек)
  • polish: False (отключаем Nelder-Mead на финальной стадии — он портит результат)
  • tol: 1e-6

Число вызовов Omega_ren: до 15 × 25 = 375, но обычно сходится раньше — ~50–75 вызовов.

6.4. Канонизация результата

После DE: 

M_canon_tol = 0.05
if M_opt < M_canon_tol:
    M_opt = 0.0
    b_opt = 0.0   # при M=0 все b эквивалентны
elif b_opt < 1e-4:
    b_opt = 0.0

7. Адаптивная сетка (Adaptive Phase Diagram)

7.1. Идея

Вместо равномерной сетки (где много точек тратится на «гладкие» области), используем квадродерево:

  • Где $\Omega$ меняется плавно — грубая сетка
  • Где $\Omega$ скачет (граница фаз) — автоматическое измельчение

7.2. Алгоритм

  1. Базовая сетка: равномерная сетка $N_\mu \times N_L$
  2. Для каждой ячейки $(\mu_1, \mu_2) \times (L_1, L_2)$:
    • Считаем $M$ и $b$ в 5 точках (углы + центр)
    • Вычисляем variation: $\text{var}_M = \max M - \min M$, $\text{var}_b = \max b - \min b$
  3. Если $\text{var}_M > \varepsilon_M$ или $\text{var}_b > \varepsilon_b$:
    • Разбиваем ячейку на 4 под-ячейки
    • Рекурсивно применяем шаг 2 (до max_depth)
  4. Иначе: записываем центр ячейки как финальную точку
