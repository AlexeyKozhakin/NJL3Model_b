## 1. Модель и обозначения

Рассматривается NJL-подобная модель в (2+1)D с компактификацией по одному пространственному направлению.

**Параметры модели:**
- $M$ — динамическая масса фермиона (вариационный параметр).
- $b$ — *[TODO: уточнить физический смысл]*.
- $L$ — *[TODO: уточнить физический смысл]* (характерный масштаб компактификации).
- $\mu$ — химический потенциал, $\mu \geq 0$.
- $\phi$ — twist-фаза граничных условий. В данном документе **$\phi = 0$**.
- $g$ — константа связи NJL-модели.

**Вспомогательные величины:**

```math
E_1 = \sqrt{M^2 + p_1^2}
```

```math
E_{\pm} = \sqrt{(E_1 \pm b)^2 + p_2^2}
```

```math
B_{\pm} = \sqrt{p_3^2 + (E_1 \pm b)^2}
```

## 2. Ренормализованный термодинамический потенциал

Полный ренормализованный потенциал $\Omega_{phys}^{ren}(M, b)$ задаётся формулой:

```math
\Omega_{phys}^{ren}(M, b) = \frac{M^2}{2g} + \Delta U_{phys}(M, b) + \Omega_{L, phys}(M, b) + \Omega_{\mu L, phys}(M, b) \tag{2.1}
```

Каждое слагаемое ниже будет разобрано отдельно.

## 3. Физические (ренормализованные) вклады

Для удаления расходимостей и вкладов свободной симметричной фазы используется следующая процедура ренормализации:

```math
X_{phys}(M, b) \equiv X(M, b) - X(0, b) + X(0, 0) \tag{3.1}
```

где $X$ может быть любым из трёх вкладов: $\Delta U$, $\Omega_L$, $\Omega_{\mu L}$.

**Смысл вычитаний:**
- $X(M, b)$ — вклад при конечных $M$ и $b$.
- $-X(0, b)$ — вычитание вклада без динамической массы ($M = 0$), что эквивалентно свободным безмассовым частицам в присутствии $b$.
- $+X(0, 0)$ — возврат вклада симметричной фазы ($M = 0, b = 0$), чтобы не потерять абсолютный уровень.

В коде (`main.py`) эта процедура реализована явно:

```python
Omega_L_phys = (fun_Omega_L(L, b, M) - fun_Omega_L(L, b, 0) + fun_Omega_L(L, 0, 0))
dU_phys      = (fun_dU_phys(b, M)      - ... )  # аналогично
Omega_mu_L_phys = (fun_Omega_L_mu_int(mu, L, b, M) - fun_Omega_L_mu_int(mu, L, b, 0) + fun_Omega_L_mu_int(mu, L, 0, 0))
```

## 4. Вакуумный вклад $\Delta U_{phys}(M, b)$

Аналитическое выражение:

```math
\Delta U_{phys}(M, b) = -\int_0^{\pi/2} d\varphi \int_0^{\infty} \frac{p\, dp}{\pi^2} \Big\{ -\frac{M^2}{p} - \sqrt{b^2 + p^2 + 2bp\cos\varphi} - \sqrt{b^2 + p^2 - 2bp\cos\varphi} + \sqrt{M^2 + b^2 + p^2 + 2b\sqrt{M^2 + p^2\cos^2\varphi}} + \sqrt{M^2 + b^2 + p^2 - 2b\sqrt{M^2 + p^2\cos^2\varphi}} \Big\} \tag{4.1}
```

### 4.1. Подстановка переменной

Интеграл по $p$ берётся от $0$ до $\infty$. Для численного интегрирования выполняется замена:

```math
p = \frac{u}{1 - u}, \qquad u \in [0, 1)
```

Отсюда:

```math
dp = \frac{du}{(1 - u)^2}, \qquad p\, dp = \frac{u\, du}{(1 - u)^3}
```

Подынтегральная функция в коде (`functions/dU.py`, `dU_int`) записана как:

```math
\text{integrand}(u, \varphi, b, M) = -\left( -\frac{M^2}{p} - \sqrt{b^2 + p^2 + 2bp\cos\varphi} - \sqrt{b^2 + p^2 - 2bp\cos\varphi} + \sqrt{M^2 + b^2 + p^2 + 2b\sqrt{M^2 + p^2\cos^2\varphi}} + \sqrt{M^2 + b^2 + p^2 - 2b\sqrt{M^2 + p^2\cos^2\varphi}} \right) \cdot \frac{p}{(1 - u)^2} \cdot \frac{1}{\pi^2} \tag{4.2}
```

где $p = u/(1-u)$. Множитель $p/(1-u)^2$ возникает из замены $p\, dp \to u\, du / (1-u)^3$, но в коде он записан как $p / (1-u)^2$, поскольку один $(1-u)$ уже учтён в $p = u/(1-u)$. Важно: **код был проверен на консистентность с формулой (4.1)**.

### 4.2. Численная реализация

Интегрирование выполняется методом средних точек (midpoint rule) на равномерной сетке по $u$ и $\varphi$:
- $u_i \in (0, 1)$, $N_h^p$ точек.
- $\varphi_j \in (0, \pi/2)$, $N_h^\varphi$ точек.

Результат:

```math
\Delta U_{phys}(M, b) \approx \sum_{i,j} \text{integrand}(u_i, \varphi_j, b, M) \cdot \Delta u \cdot \Delta \varphi
```

## 5. Компактификационный вклад $\Omega_L(M, b)$

Аналитическое выражение:

```math
\Omega_L(M, b) = -\frac{1}{L} \int \frac{dp_1 dp_3}{(2\pi)^2} \ln\Big\{ \big[1 - 2\cos(2\pi\phi)e^{-LB_+} + e^{-2LB_+}\big] \big[1 - 2\cos(2\pi\phi)e^{-LB_-} + e^{-2LB_-}\big] \Big\} \tag{5.1}
```

При $\phi = 0$ множитель $\cos(2\pi\phi) = 1$.

### 5.1. Подстановки переменных

Аналогично предыдущему разделу:

```math
p_1 = \frac{u_1}{1 - u_1}, \qquad p_3 = \frac{u_3}{1 - u_3}
```

Якобиан преобразования:

```math
dp_1 dp_3 = \frac{du_1 du_3}{(1 - u_1)^2 (1 - u_3)^2}
```

Подынтегральная функция в коде (`functions/Omega_L.py`, `Omega_L_int`) имеет вид:

```math
\text{integrand}(u_1, u_3, L, b, M) = -\frac{4}{(2\pi)^2 L} \cdot \frac{\ln\big[\text{term}_+ \cdot \text{term}_-\big]}{(1 - u_1)^2 (1 - u_3)^2} \tag{5.2}
```

где:

```math
\text{term}_{\pm} = 1 - 2e^{-LB_{\pm}} + e^{-2LB_{\pm}}
```

### 5.2. Численная реализация

Midpoint rule на сетках:
- $u_{1,i} \in (0, 1)$, $N_h^{p_1}$ точек.
- $u_{3,j} \in (0, 1)$, $N_h^{p_3}$ точек.

Результат суммируется с шагами $\Delta u_1$ и $\Delta u_3$.

## 6. Термический вклад $\Omega_{\mu L}(M, b)$ при $\phi = 0$

Аналитическое выражение:

```math
\Omega_{\mu L}(M, b) = -\frac{1}{L} \int \frac{dp_1}{2\pi} \sum_{n=-\infty}^{\infty} \Big[ F_n^+(p_1)\theta(F_n^+) + F_n^-(p_1)\theta(F_n^-) \Big] \tag{6.1}
```

где $\theta(x)$ — функция Хевисайда, а функции $F_n^{\pm}(p_1)$ определяются как:

```math
F_n^{\pm}(p_1) = \mu - \sqrt{(E_1 \pm b)^2 + \frac{4\pi^2}{L^2}(n + \phi)^2} \tag{6.2}
```

При $\phi = 0$ это упрощается до:

```math
F_n^{\pm}(p_1) = \mu - \sqrt{(E_1 \pm b)^2 + \left(\frac{2\pi n}{L}\right)^2} \tag{6.3}
```

### 6.1. Симметрия суммы по $n$ при $\phi = 0$

Поскольку при $\phi = 0$ функция $F_n^{\pm}$ зависит от $n$ только через $n^2$, выполняется симметрия:

```math
F_{-n}^{\pm}(p_1) = F_n^{\pm}(p_1)
```

Поэтому бесконечная сумма сворачивается:

```math
\sum_{n=-\infty}^{\infty} F_n^{\pm}(p_1)\theta(F_n^{\pm}) = F_0^{\pm}(p_1)\theta(F_0^{\pm}) + 2 \sum_{n=1}^{N_{max}^{\pm}} F_n^{\pm}(p_1)\theta(F_n^{\pm}) \tag{6.4}
```

**Именно поэтому в коде (`functions/Omega_mu_L.py`) используется формула:**

```python
Unp = 2*np.sum(F_tp[1:,:]) + np.sum(F_tp[0,:])
```

где `F_tp[0,:]` соответствует $n = 0$, а `F_tp[1:,:]` — всем $n \geq 1$, которые учитываются с множителем 2.

### 6.2. Определение $N_{max}^{\pm}$ при $\phi = 0$

Для каждой моды $n$ интеграл по $p_1$ ненулевой только там, где $F_n^{\pm}(p_1) > 0$. Поэтому нам нужно найти такие $n$, при которых максимум $F_n^{\pm}$ по $p_1$ положителен.

Максимум $F_n^{\pm}(p_1)$ достигается в точке, где $\sqrt{(E_1 \pm b)^2 + (2\pi n/L)^2}$ минимально. Поскольку $E_1 = \sqrt{M^2 + p_1^2} \geq M$, минимум достигается:
- при $p_1 = 0$, если $|M \pm b|$ даёт минимум;
- при $p_1 = \sqrt{b^2 - M^2}$ (только если $b > M$), если $b > M$ и знак таков, что $E_1 = b$.

Для **ветви «плюс»** ($E_1 + b$):
- Минимум $\sqrt{(E_1 + b)^2 + \dots}$ всегда при $p_1 = 0$, так как $E_1 + b \geq M + b > 0$.
- Условие $F_n^+(0) > 0$ даёт:

```math
\mu^2 > (M + b)^2 + \left(\frac{2\pi n}{L}\right)^2
```

Отсюда:

```math
N_{max}^{+} = \left\lfloor \frac{L}{2\pi} \sqrt{\mu^2 - (M + b)^2} \right\rfloor \tag{6.5}
```

Если $\mu^2 \leq (M + b)^2$, то $N_{max}^{+} = -1$ (нет ни одной моды с положительным вкладом).

*Особый случай:* если $|b| > M$ и $b < 0$, то при $p_1 = \sqrt{b^2 - M^2}$ выполняется $E_1 = |b| = -b$, и $E_1 + b = 0$. В этом случае максимум $F_n^+$ равен $\mu - 2\pi|n|/L$, и условие положительности даёт:

```math
N_{max}^{+} = \left\lfloor \frac{L\mu}{2\pi} \right\rfloor \tag{6.5a}
```

Для **ветви «минус»** ($E_1 - b$):
- Если $b \leq M$, минимум $|E_1 - b|$ при $p_1 = 0$ равен $|M - b|$.
- Условие $F_n^-(0) > 0$ даёт:

```math
N_{max}^{-} = \left\lfloor \frac{L}{2\pi} \sqrt{\mu^2 - (M - b)^2} \right\rfloor \tag{6.6}
```

- Если $b > M$, то при $p_1 = \sqrt{b^2 - M^2}$ выполняется $E_1 = b$, и $E_1 - b = 0$. Тогда максимум равен $\mu - 2\pi|n|/L$, откуда:

```math
N_{max}^{-} = \left\lfloor \frac{L\mu}{2\pi} \right\rfloor \tag{6.6a}
```

### 6.3. Пределы интегрирования по $p_1$ для фиксированного $n$

Для каждого $n \in [0, N_{max}^{\pm}]$ нужно найти область $p_1 > 0$, где $F_n^{\pm}(p_1) > 0$. Уравнение $F_n^{\pm}(p_1) = 0$ эквивалентно:

```math
(E_1 \pm b)^2 = S_n^2, \qquad S_n = \sqrt{\mu^2 - \left(\frac{2\pi n}{L}\right)^2} \tag{6.7}
```

Отсюда получаем до двух алгебраических решений для $E_1 = \sqrt{M^2 + p_1^2}$:

**PLUS:** $E_1 = S_n - b$  &nbsp;или&nbsp;  $E_1 = -S_n - b$

**MINUS:** $E_1 = S_n + b$  &nbsp;или&nbsp;  $E_1 = b - S_n$

Реальное решение для $p_1$ существует только если $E_1 \geq M$. При этом число *физических* корней (пересечений $F_n^{\pm}(p_1)$ с осью $p_1$) зависит от формы функции $F_n^{\pm}(p_1)$.

#### 6.3.1. Форма функции и число корней

Обозначим $p_{ext} = \sqrt{b^2 - M^2}$ (существует только при $|b| > M$). Производная $\partial F / \partial p_1$ пропорциональна $-(E_1 \pm b) \cdot (p_1/E_1)$. Отсюда:

- Если $|b| \leq M$, выражение $(E_1 \pm b)$ не меняет знак при $p_1 \geq 0$, поэтому $F_n^{\pm}(p_1)$ **монотонно убывает**.
- Если $|b| > M$ **и** знак перед $b$ таков, что $(E_1 \pm b)$ может обратиться в нуль (то есть для PLUS при $b < 0$ и для MINUS при $b > 0$), функция $F_n^{\pm}(p_1)$ имеет **максимум** в $p_1 = p_{ext}$.

Это приводит к трём возможным сценариям:
1. **Нет корней:** $F_n^{\pm}(0) < 0$ и максимум $\leq 0$ (такая мода не входит в $N_{max}$).
2. **Один корень:** $F_n^{\pm}(0) \geq 0$. Функция начинается выше нуля и пересекает ось один раз (монотонно убывая, либо на нисходящем участке после максимума).
3. **Два корня:** $F_n^{\pm}(0) < 0$, но максимум в $p_{ext}$ положителен. Функция отрицательна в $p_1=0$, растёт до максимума, пересекает ноль ($p_{left}$), достигает максимума, падает и снова пересекает ноль ($p_{right}$).

**Важно:** случай с двумя корнями реализуется только благодаря особым формулам $n_{max}$ при $|b| > M$, которые позволяют $
 \geq 0$ даже при $F_n^{\pm}(0) < 0$ (см. (6.5a) и (6.6a)).

#### 6.3.2. Явные формулы для корней

Приводим итоговые формулы для всех случаев. Условие $F(0) < 0$ для двух корней эквивалентно:
- **PLUS, $b < -M$:** $\mu < |b| - M$
- **MINUS, $b > M$:** $\mu < b - M$

| Ветвь | Условие | $|b|$ vs $M$ | $F(0)$ | Корней | $p_{left}$ | $p_{right}$ |
|:-----:|:-------:|:------------:|:------:|:------:|:-----------|:------------|
| PLUS | $b > 0$ | — | $\geq 0$ | 1 | $0$ | $\sqrt{(S_n - b)^2 - M^2}$ |
| PLUS | $b < 0$ | $\|b\| \leq M$ | $\geq 0$ | 1 | $0$ | $\sqrt{(S_n + |b|)^2 - M^2}$ |
| PLUS | $b < 0$ | $\|b\| > M$ | $\geq 0$ | 1 | $0$ | $\sqrt{(S_n + |b|)^2 - M^2}$ |
| PLUS | $b < 0$ | $\|b\| > M$ | $< 0$ | **2** | $\sqrt{(|b| - S_n)^2 - M^2}$ | $\sqrt{(|b| + S_n)^2 - M^2}$ |
| MINUS | $b < 0$ | — | $\geq 0$ | 1 | $0$ | $\sqrt{(S_n + |b|)^2 - M^2}$ |
| MINUS | $b > 0$ | $b \leq M$ | $\geq 0$ | 1 | $0$ | $\sqrt{(S_n + b)^2 - M^2}$ |
| MINUS | $b > 0$ | $b > M$ | $\geq 0$ | 1 | $0$ | $\sqrt{(S_n + b)^2 - M^2}$ |
| MINUS | $b > 0$ | $b > M$ | $< 0$ | **2** | $\sqrt{(b - S_n)^2 - M^2}$ | $\sqrt{(b + S_n)^2 - M^2}$ |

В случае одного корня интегрирование ведётся по $[0, p_{right}]$. В случае двух корней — по $[p_{left}, p_{right}]$.

### 6.4. Последствия для численной реализации

Текущий код (`functions/Omega_mu_L.py`, `integration_limits_plus` / `integration_limits_minus`) жёстко закодирован с $p_{left} \equiv 0$. Как показано в таблице выше, это корректно для всех случаев с одним корнем, но **некорректно для случаев с двумя корнями**.

Кроме того, в исходной версии кода (до исправлений в ветке `docs-and-verification`) были ошибки в знаках при вычислении $p_{right}$ для некоторых комбинаций ветви и знака $b$.

**Алгоритмически**, для поддержки двух корней требуется:
1. В `integration_limits_*` определять не только $p_{right}$, но и корректный $p_{left}$.
2. В `fun_Omega_L_mu_int` для каждой моды $n$ с двумя корнями выполнять интегрирование по отрезку $[p_{left}^{(n)}, p_{right}^{(n)}]$ вместо $[0, p_{right}^{(n)}]$.
3. Случаи с двумя корнями возникают только при $|b| > M$ и только для малых $n$ (где $F(0) < 0$). Для больших $n$ (при которых $F(0) \geq 0$) снова остаётся один корень $p_{right}$. Можно оптимизировать, вычисляя пороговое $n^*$:

```math
n^* = \frac{L}{2\pi}\sqrt{\mu^2 - (|b| - M)^2}
```

(для соответствующей ветви и знака $b$). При $n > n^*$ корней два, при $n \leq n^*$ — один. Однако при небольших $L$ и $
$ общее число мод $N_{max}$ само по себе мало, поэтому даже покадровая проверка `if` в цикле по $n$ не критична для производительности.
