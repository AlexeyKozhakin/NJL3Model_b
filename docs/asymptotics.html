Асимптотика $\Omega(\mu \to \infty)$ при $L = 1$, $g = -1$

1. Постановка задачи

Перенормированный потенциал NJL₃-модели с хиральным химическим потенциалом $b$:

\[ \Omega_{\text{ren}}(M, b; \mu, L, g) = \frac{M^2}{2g} + \Delta U_{\text{phys}}(M, b) + \Omega_{L,\text{phys}}(M, b; L) + \Omega_{\mu L,\text{phys}}(M, b; \mu, L) \]

где перенормированная $\mu L$-часть имеет вид:

\[ \Omega_{\mu L,\text{phys}} = \bigl[\Omega_{\mu L}(M, b) - \Omega_{\mu L}(0, b)\bigr] + \Omega_{\mu L}(0, 0) \]

При вычислении фазовой диаграммы методом differential_evolution обнаружилось, что граница фазового перехода при $g = -1$ лежит при $\mu \approx 3.2$ (независимо от $L$). Возникает вопрос: почему именно этот масштаб? Для ответа изучена асимптотика $\Omega_{\mu L}$ при $\mu \to \infty$.

3. Аналитический вывод

3.1. Структура ΩμL

Конечно-температурная (по $L$) часть потенциала записывается через сумму по модам $n$:

\[ \Omega_{\mu L} = -\frac{2}{L}\sum_{s=\pm}\sum_{n=0}^{n_{\max}^{(s)}} \int_{\mathcal{D}_n^{(s)}} dp_1\; F_{s}(p_1, n; M, b, L, \mu) \]

где подынтегральная функция (для $s = +$):

\[ F_{+}(p_1, n) = \frac{1}{2\pi}\left[\mu - \sqrt{(E_1 + b)^2 + \left(\frac{2\pi n}{L}\right)^2}\right]_{+} \]

с $E_1 = \sqrt{M^2 + p_1^2}$ и $[x]_{+} = \max(x, 0)$. Область интегрирования $\mathcal{D}_n^{(s)}$ определяется из условия $F_s > 0$.

3.2. Лимит μ → ∞

При $\mu \gg M, b, 1/L$ число мод $n_{\max} \sim L\mu / (2\pi) \gg 1$. Заменяем сумму по $n$ на интеграл по $k_2 = 2\pi n / L$:

\[ \sum_{n} \;\longrightarrow\; \frac{L}{2\pi} \int dk_2 \]

Тогда для одной ветви (например, $s=+$):

\[ U_{n}^{(+)} \approx \frac{L}{(2\pi)^2} \int_{-\mu}^{\mu} dk_2 \int_{0}^{\sqrt{\mu^2 - k_2^2}} dp_1 \left[\mu - \sqrt{(E_1 + b)^2 + k_2^2}\right] \]

Переходим к полярным координатам $(p_1, k_2) = (\rho\cos\theta, \rho\sin\theta)$ и раскладываем подкоренное выражение по $1/\mu$:

\[ \sqrt{(E_1 + b)^2 + k_2^2} = \sqrt{\rho^2 + 2E_1 b + b^2 + M^2} = \rho\sqrt{1 + \frac{M^2 + 2E_1 b + b^2}{\rho^2}} \]

Главный член ($\sim \mu^3$) получается при $M = b = 0$:

\[ \Omega_{\mu L}(0, 0) \xrightarrow{\mu\to\infty} -\frac{L\mu^3}{6\pi} \]

3.3. Поправка ∼ M²μ

Разложение подынтегральной функции по $M^2/\mu^2$ при фиксированном $b$ даёт:

\[ \Omega_{\mu L}(M, b) - \Omega_{\mu L}(0, 0) \;\xrightarrow{\mu\to\infty}\; \frac{M^2 \mu}{2\pi} + \mathcal{O}(M^4/\mu) \]

Коэффициент $1/(2\pi)$ подтверждается численно с точностью лучше $1\%$ (см. таблицу выше).

Теорема (асимптотика $\Omega_{\mu L}$ при $\mu \to \infty$).
При $L = 1$ и фиксированных $M, b$: \[ \Omega_{\mu L}^{\text{phys}}(M, b; \mu) = -\frac{\mu^3}{6\pi} + \frac{M^2 \mu}{2\pi} + \mathcal{O}(\mu^0) \] Первый член не зависит от $(M, b)$, второй зависит только от $M$ (линейно от $b$ зависимость исчезает в лидирующем порядке).

4. Физические следствия

4.1. Полный потенциал при μ → ∞

Подставляя асимптотику в $\Omega_{\text{ren}}$:

\[ \Omega_{\text{ren}}(M, b) \;\xrightarrow{\mu\to\infty}\; \underbrace{\frac{M^2}{2g}}_{\text{вакуум}} + \underbrace{\Delta U_{\text{phys}} + \Omega_{L,\text{phys}}}_{\text{константа } \sim \mu^0} - \underbrace{\frac{L\mu^3}{6\pi}}_{\text{общий сдвиг}} + \underbrace{\frac{M^2 \mu}{2\pi}}_{\text{критический}} \]

4.2. Критическая точка для g = −1

Для $g = -1$ вакуумный член даёт $-M^2/2$. Конкуренция по $M$ определяется знаком:

\[ \frac{\partial^2 \Omega_{\text{ren}}}{\partial M^2}\bigg|_{M=0} = \frac{1}{g} + \frac{\mu}{\pi} = -1 + \frac{\mu}{\pi} \]
Критическое значение химического потенциала: \[ \boxed{\mu_c = \pi |g| = \pi \approx 3.1416} \] При $\mu < \pi$ стабильна низкая фаза ($M > 0, b > 0$).
При $\mu > \pi$ стабильна высокая фаза ($M = 0, b = 0$).
Сравнение с численным результатом:
Численная фазовая диаграмма (адаптивное измельчение 10×10, DE, $g = -1$) даёт границу перехода при $\mu \approx 3.2$, что совпадает с аналитической оценкой $\mu_c = \pi$ с точностью $\sim 2\%$. Незначительное отличие объясняется конечным разрешением сетки и конечной точностью DE-оптимизации.

4.3. Роль b-зависимости

Поскольку линейный по $\mu$ член пропорционален $M^2$ и не зависит от $b$, при $\mu \to \infty$ хиральный потенциал $b$ перестаёт влиять на положение минимума по $M$. Однако в промежуточной области ($\mu \sim 1\text{–}3$) $b$-зависимость критически важна — именно узкие минимумы по $b$ (шириной $\sim 0.2$–$0.4$) требуют применения differential_evolution вместо стандартного Nelder-Mead.

5. Заключение

  1. Установлена точная асимптотика $\Omega_{\mu L}^{\text{phys}} \sim -\mu^3/(6\pi) + M^2\mu/(2\pi)$ при $\mu \to \infty$.
  2. Лидирующий $\mu^3$-член универсален (не зависит от $M, b$), что объясняет канонизацию $b = 0$ при $M = 0$.
  3. Линейный по $\mu$ член $\propto M^2$ приводит к фазовому переходу при $\mu_c = \pi |g|$.
  4. Численная фазовая диаграмма подтверждает аналитическую оценку $\mu_c \approx \pi$.
