### Этап 1.2 — Упрощённые функции для ренормализации

> Ренормализация требует трёх уровней каждой функции:
> `f(b,M)` (полный), `f(b,0)` (M=0, проще), `f(0,0)` (b=M=0, ещё проще).
> Члены `f(b,0)` и `f(0,0)` считаются **один раз** и кэшируются —
> поэтому их скорость критична.

- [ ] Получить и изучить код пользователя для `Omega_muL(mu,L,0,0)` (b=0, M=0)
- [ ] Получить и изучить код пользователя для `Omega_muL(mu,L,b,0)` (M=0)
- [ ] Реализовать `gpu/functions/Omega_muL_00_torch.py` — b=0, M=0
  - [ ] Тест: совпадение с Numba `fun_Omega_L_mu_int(mu,L,0,0)` на 10 точках
- [ ] Реализовать `gpu/functions/Omega_muL_b0_torch.py` — M=0, b≠0
  - [ ] Тест: совпадение с Numba `fun_Omega_L_mu_int(mu,L,b,0)` на 10 точках
- [ ] Реализовать упрощённые случаи `dU(b,0)` и `dU(0,0)=0`
- [ ] Реализовать упрощённые случаи `Omega_L(L,b,0)` и `Omega_L(L,0,0)`

- [ ] Сохранить `cache/Omega_L.pt`

---

### Этап 1.5 — `gpu/functions/Omega_muL_torch.py`

- [ ] Реализовать двухуровневый батчинг:
  - внешний цикл по `mu` (N_MU итераций)
  - внутренний цикл по чанкам `(b, M)` размером `C×C`
  - пиковая память ≈ 750 MB при любом размере сетки
- [ ] ReLU вместо явных границ:
  - `F_plus  = clamp((mu - sqrt((E1+b)^2 + (2*pi*n/L)^2)) / 2*pi, min=0)`
  - `F_minus = clamp((mu - sqrt((E1-b)^2 + (2*pi*n/L)^2)) / 2*pi, min=0)`
- [ ] Маска по n: занулять строки где `n > n_max(mu,L,b,M)`
- [ ] Коэффициенты C_n: 1 при n=0, 2 при n>0
- [ ] Тест: совпадение с `fun_Omega_L_mu_int` (Numba) на 10 точках
  - [ ] включая двухкорневые случаи (|b| > M)
  - [ ] включая граничные случаи (mu маленький, n_max = -1)
- [ ] Сохранить `cache/Omega_muL.pt`

---

### Этап 1.6 — Ренормализация и сборка `Omega_ren`

- [ ] Вычислить физические комбинации из кэшей:
  - `dU_phys       = dU(b,M)       - dU(b,0)       + dU(0,0)`
  - `OmegaL_phys   = OmegaL(L,b,M) - OmegaL(L,b,0) + OmegaL(L,0,0)`
  - `OmegamuL_phys = OmegamuL(b,M) - OmegamuL(b,0)  + OmegamuL(0,0)`
- [ ] Сборка через broadcast — тензор `(N_MU, N_L, N_B, N_M)` ≈ 25–400 MB
- [ ] Тест: значение `Omega_ren` для 5 точек совпадает с `Omega_ren_fast.py`
