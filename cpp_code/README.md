# Пример C++ реализации Omega_mu_L

## Как скомпилировать на Mac

1. Установите компилятор (если не установлен):
   ```sh
   xcode-select --install
   ```
2. Перейдите в каталог:
   ```sh
   cd cpp_code
   ```
3. Скомпилируйте:
   ```sh
   g++ omega_mu_L.cpp -o omega_mu_L -O3 -fopenmp
   ```
4. Запустите:
   ```sh
   ./omega_mu_L
   ```

## Описание
- В файле `omega_mu_L.cpp` реализованы основные функции для расчёта Omega_mu_L.
- Используется OpenMP для параллелизации по всем параметрам.
- Результаты сохраняются в текстовый файл `Omega_ren_phys.txt`.
- Пример параметров и структуры аналогичен Python-версии.

## Важно
- Для реального переноса нужно реализовать точные границы интегрирования и логику n_max_plus/n_max_minus.
- Данный пример — шаблон для быстрой адаптации и тестирования производительности.
