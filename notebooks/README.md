# Отладочные скрипты

Эта директория содержит интерактивные Python-скрипты для пошаговой проверки формул и численных методов. Каждый скрипт можно запускать целиком (`python notebooks/XX_...py`) или копировать по секциям в Jupyter/VS Code.

## Нумерация

- `01_test_omega_mu_L_b_symmetry.py` — проверка симметрии $b \to -b$ в `Omega_mu_L`.
- `02_...` — будущие скрипты (пределы интегрирования, сходимость по сетке, сравнение с аналитикой и т.д.).
